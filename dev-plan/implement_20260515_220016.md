# implement_20260515_220016.md

작성 일시: `2026-05-15 22:00:16 KST`

이 문서는 안정화 목적의 route/module 분리 범위를 고정하고, 확장 기능 개발로 번지는 것을 막기 위한 작업 문서다.

## 개발 목적

- S-1 downstream session invalidation hook은 완료로 간주한다.
- 다음 안정화 순서인 `/mcp` endpoint router + MCP dispatcher 분리를 완료한다.
- 그 다음 `mcp-services` admin router를 분리해 `main.py` 비대화를 완화한다.
- Plugin Framework는 확장 기능으로 번지지 않도록 이번 턴에서는 closed-by-default hook boundary만 추가하고, 외부 loading/built-in plugin/API/CLI는 후속으로 남긴다.

## 개발 범위

- `/mcp` POST/GET/DELETE route registration을 `coremcp.api.mcp_endpoint`로 이동.
- JSON-RPC dispatch matrix를 `coremcp.mcp.dispatcher`로 이동.
- `/v1/mcp-services*` admin route registration을 `coremcp.api.services`로 이동.
- 기존 테스트 계약을 유지하고 structural facade 테스트에 새 route module export를 포함.
- TESTING/README/테스트 계획 문서를 실제 구조와 테스트 결과에 맞게 갱신.

## 제외 범위

- 외부 plugin loading, built-in plugin 정책, plugin API/CLI.
- Access Groups, OTel, Inspector 등 기능 확장.
- 전체 FastAPI router 완전 분리.
- 전체 repository call-site migration.
- SaaS/team/workspace/marketplace/billing 기능.
