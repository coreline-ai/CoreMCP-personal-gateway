- [ ] `_schemas.py` 에 OAuth schemas — `OAuthProtectedResourceMetadata`, `OAuthAuthorizationServerMetadata`, `JWKSet` (외부 spec 기반)

- [ ] `/v1/external-connections/one-time-token` (POST), `/v1/external-connections/exchange` (POST), `/v1/external-connections` (POST) 에 response_model 부여
- [ ] DELETE 응답들 — accepted 또는 boolean shape — `AcceptedResponse` 공통 schema
