작성 일시: `2026-05-13 20:56:27 KST`

이 문서는 CoreMCP의 실제 1차 연결 대상을 Claude Code bearer 수동 등록이 아니라 **Codex CLI `exec`에서 사용하는 CoreMCP MCP 연결**로 전환하고, 이미 계획한 Web Admin 디자인 적용 상태를 Codex 연결 UX까지 반영하기 위한 작업 문서다.

## 개발 목적

CoreMCP는 개인용 MCP Gateway다. 현재 구현은 Claude Code bearer 예시가 곳곳에 남아 있으므로, 실제 사용 흐름을 Codex CLI 기준으로 바꾼다. Codex는 `codex mcp add --url ... --bearer-token-env-var ...`로 CoreMCP `/mcp`를 등록하고, `codex exec` 실행 시 해당 MCP server를 사용할 수 있어야 한다.

## 개발 범위

- Codex CLI MCP 등록/실행 helper script 추가.
- Codex 전용 client token 발급/저장/환경변수 주입 흐름 추가.
- Web Admin Connected Clients copy와 기본값을 Codex CLI exec 우선으로 변경.
- `codex_cli` client profile을 코드/스키마/테스트에 반영.
- README/TESTING/coremcp-docs/AGENTS의 핵심 Quick Start와 목표 문구를 Codex CLI 기준으로 정정.
- 기존 디자인 primitive(`cm-*`) 적용 상태를 유지한다.

## 제외 범위

- Codex 자체 모델/API 기능 변경.
- 외부 LLM API dependency 추가.
- OAuth 강제 전환.
- Claude Code 지원 제거. Claude Code는 optional compatibility로 남긴다.
- 실제 유료 `codex exec` LLM 호출 자동 테스트. 기본 smoke는 non-LLM MCP transport 검증으로 제한한다.
