## Phase 2. `make register-mcp` generic macro

### 목표

현재 stdio MCP 등록은 MCP 마다 별도 스크립트 (`register-project-docs-mcp.sh`, `register-git-workspace-mcp.sh`) — 새 도구 시도 시 매번 스크립트 복사·수정 필요. 일반 macro `make register-mcp` 한 줄로 등록 가능하게.

### 구현 태스크

- [ ] `infra/scripts/register-mcp.sh` 신설 — 인자 파싱 + slug/name/command/args/cwd/env 일반화
  - 환경 변수 입력: `MCP_NAME`, `MCP_SLUG`, `MCP_DESCRIPTION`, `MCP_COMMAND`, `MCP_ARGS` (JSON array), `MCP_CWD`, `MCP_ENV` (JSON object), `MCP_CATEGORY`
  - 또는 CLI flags `--name "..." --slug "..." --command python3 --args '["-m", "foo"]' --cwd "..."`
  - 기존 register-project-docs-mcp.sh 패턴 (admin token 읽기, 서비스 create/update, toolbox 추가, validate) 동일하게 사용
- [ ] `Makefile` 에 `register-mcp` 타깃 추가 — 환경변수 기반:
  ```make
  register-mcp:
      MCP_NAME="$(MCP_NAME)" MCP_SLUG="$(MCP_SLUG)" ... infra/scripts/register-mcp.sh
  ```
- [ ] 검증: 기존 `make project-docs-register` 와 동일하게 호출해서 같은 결과 확인 (smoke)
- [ ] 기존 `register-project-docs-mcp.sh` / `register-git-workspace-mcp.sh` 는 그대로 유지 (back-compat). 두 스크립트가 `register-mcp.sh` 를 호출하는 thin wrapper 로 재작성 (선택, 시간 되면)
