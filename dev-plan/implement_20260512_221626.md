## 개발 범위

- Fernet fallback vault 실제 암호화 구현 및 회귀 테스트.
- Next.js 보안 헤더(CSP, nosniff, frame deny 등) 적용.
- daily backup launchd plist 추가 및 ops smoke 검증 확장.
- Playwright route smoke claim을 실제 스크립트 또는 문서 정정 중 하나로 정합화.
- client token 자기비교 dead code 제거.
- post-reboot/Tailscale smoke가 단순 flag가 아니라 검증 가능한 상태를 출력하도록 개선.

## 제외 범위

- Tailscale 설치/로그인/Serve 설정 변경.
