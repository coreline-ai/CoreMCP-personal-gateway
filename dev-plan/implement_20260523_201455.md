## Phase 2. JobsRepository composition sample (ADR-046)

### 목표

`JobsRepositoryMixin` 을 다중상속 mixin 에서 **composition 클래스** (`JobsRepository(repository)`) 로 완전 전환. Repository 는 mixin 상속을 끊고 `self.jobs = JobsRepository(self)` 로 보유. 기존 호출 `repository.create_job(...)` 은 `__getattr__` delegation 또는 explicit alias 로 호환 유지.

### 구현 태스크

- [ ] `JobsRepository(repository: Repository)` 신설 (mixin 메서드 그대로 보유, host 참조는 `self._repo.db` 등으로 명시 변경)
- [ ] `Repository.__init__` 에 `self.jobs = JobsRepository(self)` 추가
- [ ] `Repository.create_job` / `update_job` / `get_job` / `mark_stuck_jobs_failed` 가 `self.jobs.X` 로 delegate (backward compat 4 메서드)
- [ ] `Repository` 의 mixin 상속에서 `JobsRepositoryMixin` 제거
- [ ] `repository_jobs.py` 의 mixin 클래스는 backward compat 위해 `JobsRepository` 와 동의어로 alias (또는 제거 후 import 정리)
- [ ] ADR-046 갱신 — Step 1 의 진짜 facade composition 완료 기록

### 자체 테스트

- [ ] `uv run pytest -q` 통과 — `repository.create_job(...)` 호출 site 영향 없음
- [ ] `uv run pyright` 0 errors
- [ ] coverage gate 유지

### 완료 조건

- [ ] Jobs 만 완전 composition, 나머지 mixin 은 TYPE_CHECKING 패턴 유지 (다음 cycle)
- [ ] 회귀 통과
