이 문서는 이번 개발의 범위를 고정하고, 구현이 목적 밖으로 확장되지 않도록 하기 위한 작업 문서다.

## 개발 목적
- 확장 개발 없이, 남은 구조 안정화 후보를 작은 단위로 적용한다.
- MCP initialize session header, tools/call 함수 응집도, services router 패턴, repository 본체 분해 시작점을 안정화한다.

## 개발 범위
- initialize RPC에서는 cached downstream session header를 보내지 않도록 helper 옵션을 추가한다.
- `handle_tools_call` 내부를 prepare / cache / route / policy / downstream execution stage helper로 분리한다.
- `register_services_routes`를 `APIRouter` 기반 등록 패턴으로 정리한다.
- `repository.py` 본체 도메인 분해는 low-risk jobs domain부터 물리 분리한다.
- Plugin resources/prompts hook은 ADR-041 기준 보류한다.
- 구현 후 코드 레벨 안정성 리뷰를 수행한다.

## 제외 범위
- built-in plugin 추가, resources/prompts plugin hook 확장, external plugin loading은 제외한다.
- `repository.py` 전체 SQL 이동은 제외하고, 작고 안전한 jobs domain first slice만 진행한다.
- UX 기능 변경, SaaS/team/marketplace/billing 기능은 제외한다.
- 외부환경 검증(reboot/Tailscale/real OAuth/mobile/long soak)은 제외한다.
