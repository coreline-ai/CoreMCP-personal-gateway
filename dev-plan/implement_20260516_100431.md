작성 일시: `2026-05-16 10:04:31 KST`

이 문서는 이번 개발의 범위를 고정하고, 구현이 목적 밖으로 확장되지 않도록 하기 위한 작업 문서다.

## 개발 목적
- 확장 개발 없이 남은 구조 안정화 후보를 계속 처리한다.
- repository credential/token/OAuth domain, API dependency boundary, services endpoint 내부 구조를 점진 정리한다.

## 개발 범위
- `repository.py`의 client token, one-time connection token, OAuth persistence, service credential SQL을 `repository_credentials.py` mixin으로 분리한다.
- `connections`, `toolboxes`, `oauth` 라우트에 `Depends(...)` provider를 점진 적용한다.
- `services.py` 내부 endpoint handler에서 credential create/rotate helper를 추가 분리한다.
- built-in plugin과 resources/prompts plugin hook은 계속 보류한다.

## 제외 범위
- built-in plugin 구현, resources/prompts plugin hook 구현은 제외한다.
- repository 전체 SQL 이동은 제외하고 credentials/token/OAuth domain 1개만 추가 분리한다.
- UX/기능 변경, SaaS/team/marketplace/billing 기능은 제외한다.
- 외부환경 검증은 제외한다.
