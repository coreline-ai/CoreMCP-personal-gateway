# implement_20260515_214318.md

작성 일시: `2026-05-15 21:43:18 KST`

이 문서는 CoreMCP 구조 refactor 다음 단계로 OAuth route group을 `coremcp.api.oauth` 모듈로 분리하기 위한 작업 범위를 고정한다.

## 개발 목적
- `main.py` route 과밀도를 줄이고 OAuth/OIDC metadata + token endpoints를 독립 route module로 이동한다.
- 기존 optional `AUTH_MODE=oauth` 동작, DCR/CIMD rate limit, PKCE/token/refresh/introspection/revoke behavior를 유지한다.
- 이후 MCP endpoint router, services router 분리의 안전한 선례를 만든다.

## 개발 범위
- `apps/api/coremcp/api/oauth.py` 신설.
- `register_oauth_routes(app, ...)`로 OAuth well-known/JWKS/register/authorize/token/revoke/introspect route 등록.
- OAuth route 전용 helper(`form_or_json_body`, `oauth_error_response`, `check_oauth_dcr_rate_limit`) 이동.
- `oauth_issuer`, `oauth_resource`는 main의 MCP auth verifier에서도 쓰므로 oauth module에서 export하고 main이 import한다.
- route response shape/status/cache headers 유지.

## 제외 범위
- OAuth business logic 변경.
- consent UI 추가.
- 실제 external OAuth client 검증.
- MCP endpoint/services/toolbox router 분리.
- repository call-site migration.

## 공통 진행 규칙
- `AUTH_MODE=static_bearer` default를 유지한다.
- OAuth optional mode에서만 OAuth endpoints가 응답해야 한다.
- DCR rate-limit key, no-store headers, resource indicator validation을 유지한다.
- token boundary invariant를 변경하지 않는다.
