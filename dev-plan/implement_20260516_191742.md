## 개발 목적
- M-3 Plugin Framework 본격화 전에 closed-by-default 보안 경계를 다시 고정한다.
- Q-2로 제기된 `resources_handlers.py` / `prompts_handlers.py` plugin hook 비대칭을 ADR-040/041 기준으로 판정한다.
- 안전 선행 조건 없이 resources/prompts raw content/prompt message 경계가 확장되지 않도록 회귀 테스트를 추가한다.

## 개발 범위
- Plugin Framework 안정화 계획 문서화.
- `resources/read`, `prompts/get` hook 적용 여부 검토.
- ADR-041과 충돌하는 hook 확장은 보류하고, 비활성 상태를 테스트로 고정.
- `PluginRegistry` 기본 empty registry 동작 회귀 테스트 보강.

## 제외 범위
- built-in plugin 자체 구현.
- 외부 plugin loading, dynamic Python import, network fetch, marketplace/plugin registry.
- SaaS/team/workspace/publisher/billing 기능.
- `web/API/repository` 구조 변경.
- resources/prompts raw payload를 audit/log/debug trace에 저장하는 기능.

- ADR-041: 현재 hook 적용 범위는 `tools/call`로 제한한다.
- ADR-041: `resources/read`, `prompts/get`은 raw content와 prompt message를 직접 다루므로 built-in plugin별 보안 ADR과 전용 테스트 전까지 hook 확장을 보류한다.
