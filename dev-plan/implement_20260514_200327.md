# implement_20260514_200327.md

작성 일시: `2026-05-14 20:03:27 KST`

이 문서는 구조성 백로그를 CoreMCP 개인용 gateway 목적에 맞게 정리하고, 구현이 SaaS/마켓플레이스 방향으로 확장되지 않도록 범위를 고정하기 위한 작업 문서다.

## 개발 목적
- OAuth 옵션 모드가 launchd 재시작 후에도 최소 운영 연속성을 갖도록 키/클라이언트/토큰 상태를 영속화한다.
- SSRF guard를 DNS rebinding race에 더 강하게 보강한다.
- SQLite schema drift를 줄이고 Alembic/부트스트랩의 단일 출처 원칙을 강화한다.
- 대형 파일 분해는 기능 리스크가 큰 전면 리팩터링 대신, 후속 분해가 가능한 foundation만 반영한다.

## 개발 범위
- `apps/api` 중심 구조 개선.
- OAuth RSA key, DCR client, auth code, refresh token, revoked access JTI, CIMD cache DB persistence.
- SSRF URL 검증 강화 및 테스트.
- schema source 문서화/모듈화, SQLAlchemy dead path 정리 여부 판단.
- OAuth consent는 개인용 범위에서 운영 경고 또는 minimal consent gate로 제한.

## 제외 범위
- SaaS workspace/team/marketplace/publisher/billing 기능.
- 외부 LLM API 의존성 추가.
- 전체 ORM 전환 같은 대규모 SQLAlchemy rewrite.
- main.py/repository.py 전면 분해로 인한 라우트 동작 변경.
