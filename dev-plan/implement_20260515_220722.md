# implement_20260515_220722.md

작성 일시: `2026-05-15 22:07:22 KST`

이 문서는 남은 구조 안정화 후보 중 즉시 안전하게 진행 가능한 route 추가 분리와 repository facade call-site migration 범위를 고정한다.

## 개발 목적

- `main.py`에 남은 admin route 중 client token / external connections / toolboxes / playground route를 분리한다.
- 분리된 route module 내부에서는 가능한 범위에서 `app.state.repos.*` domain facade를 사용한다.
- Plugin Framework built-in/외부 loading은 보안 ADR 전까지 구현하지 않는다.

## 개발 범위

- `coremcp.api.connections`: client token + external connections route registration.
- `coremcp.api.toolboxes`: 도구함 route registration.
- `coremcp.api.playground`: playground route registration.
- route module export 및 structural smoke 갱신.
- 관련 문서와 테스트 결과 갱신.

## 제외 범위

- 전체 FastAPI router 완전 분리.
- repository.py 본체 도메인 분해.
- 전체 call-site migration.
- Plugin Framework built-in, 외부 plugin loading, API/CLI.
- SaaS/team/workspace/marketplace/billing 기능.
