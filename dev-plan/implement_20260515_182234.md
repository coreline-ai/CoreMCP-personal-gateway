# implement_20260515_182234.md

작성 일시: `2026-05-15 18:22:34 KST`

이 문서는 CoreMCP personal gateway의 안정화 후속 작업 중 `main.py`/`repository.py` 구조 분해, bidirectional RPC 정책 ADR, 실제 외부환경 검증 runbook 보강을 병렬 에이전트로 진행하기 위한 범위를 고정한다.

## 개발 목적
- `main.py` 3,800+ LOC, `repository.py` 1,900+ LOC의 증가 속도를 낮추기 위해 안전한 모듈 경계를 먼저 도입한다.
- 기존 public API와 테스트를 깨지 않으면서 도메인별 import/facade를 마련해 다음 refactor cycle의 위험을 낮춘다.
- MCP bidirectional RPC(`sampling/*`, `roots/*`, `elicitation/*`)는 즉시 구현하지 않고 personal gateway 보안/라우팅 정책을 ADR로 확정한다.
- 실제 reboot/Tailscale/OAuth client/mobile/long soak 검증은 환경 의존 작업이므로 운영 host에서 재현 가능한 helper/runbook으로 정리한다.

## 개발 범위
- `apps/api/coremcp/main.py`에서 순수 helper 중심으로 `apps/api/coremcp/mcp/*` 모듈을 추출하고 기존 라우트 동작을 유지한다.
- `apps/api/coremcp/db/repository.py`를 즉시 파괴적으로 쪼개지 않고, 도메인별 repository facade/wrapper 모듈을 추가해 점진 migration 경로를 만든다.
- `coremcp-docs/13-adr.md`에 bidirectional RPC 정책 ADR을 추가한다.
- `infra/scripts/*`, `Makefile`, `TESTING.md`, `coremcp-docs/12-operations.md`에 외부환경 검증 명령/결과 기록 흐름을 보강한다.
- 구조 회귀 테스트와 핵심 API 테스트를 보강한다.

## 제외 범위
- SaaS/team/workspace/marketplace/billing 기능.
- 외부 LLM API 연동.
- `sampling/createMessage`, `elicitation/*`, `roots/list`의 실제 bidirectional RPC 구현.
- 실제 macOS reboot, Tailscale 로그인/ACL 변경, 실제 외부 OAuth provider 등록, 실제 모바일 기기 수동 QA, 장시간 soak의 대리 실행. 이 항목은 운영 host에서 runbook으로 수행한다.
- 전체 FastAPI router 분리와 전체 repository call-site migration을 한 번에 완료하는 빅뱅 refactor.
