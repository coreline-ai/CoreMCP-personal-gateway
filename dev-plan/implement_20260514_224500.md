# implement_20260514_224500.md

작성 일시: `2026-05-14 22:45:00 KST`

이 문서는 이번 안정화 batch의 범위를 고정하고, backend/CLI worker 산출물을 통합한 뒤 실제 검증 결과를 기록하기 위한 작업 문서다.

## 개발 목적

CoreMCP 개인 gateway가 이미 구현한 P0/P1/P2 기반 위에, 운영 안정화와 release hygiene을 보강한다. 이번 문서 worker의 직접 범위는 dev-plan/docs 정리이며, backend/CLI worker의 코드 변경 결과는 통합 검증 후 반영한다.

## 개발 범위

- Phase 1: commit split 계획을 문서화하고, 이 code patch가 commit/push를 수행하지 않는다는 점을 명시한다.
- Phase 2: STDIO downstream process resource limit hardening을 구현/검증한다.
- Phase 3: admin/MCP 경로별 rate limit hardening을 구현/검증한다.
- Phase 4: CLI import/export hardening을 구현/검증한다.
- Phase 5: `main.py` / `repository.py` future module split 계획을 behavior-preserving refactor로 정리한다.
- Phase 6: external-env / mobile / soak 운영 명령과 남은 항목 분류를 최신 batch 표현으로 동기화한다.

## 제외 범위

- 본 문서 worker가 `apps/api/**`, `apps/web/**`, `Makefile`을 수정하는 것.
- 본 patch에서 commit split, commit, push, PR 생성까지 수행하는 것. commit split은 권장 계획이며, 사용자가 `commit/push`를 명시 요청할 때 별도 실행한다.
- SaaS / team / workspace / marketplace / publisher / billing 기능.
- 외부 LLM API 의존성 추가.
- 통합 검증 없이 완료를 단정하는 문서 변경.
