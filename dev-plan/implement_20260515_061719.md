# implement_20260515_061719 — Multi-MCP Stabilization Pass

## 목적

멀티 MCP aggregator 관점에서 남은 안정화 결함을 personal gateway 범위 안에서 보강한다.
이미 구현된 단일 MCP 명세 패치(listChanged category, SSE replay, JSON-RPC batch, progress/resource notification fan-out, stdio cap)는 유지하고, 아래 영역만 추가 패치한다.

## 범위

- P0/P1: Tool namespace prefix 우회 제거
- P0/P1: `resources/read` catalog miss broadcast 제거
- P0/P1: 동일 URI resource collision의 비결정적 first-hit 제거
- P0/P1: HTTP downstream `Mcp-Session-Id` 매핑
- P1: downstream `notifications/*/list_changed` fan-in
- 테스트/문서 업데이트
