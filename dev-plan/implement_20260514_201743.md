# implement_20260514_201743.md

작성 일시: `2026-05-14 20:17:43 KST`

이 문서는 MCP 기능 확장 제안을 CoreMCP 개인용 gateway 목적에 맞게 선별하고, 다음 구현을 안전하게 쪼개기 위한 작업 문서다. SaaS/team/marketplace/billing 방향으로 확장하지 않고, 실제 로컬 운영 가치와 MCP 호환성을 높이는 항목만 포함한다.

## 개발 목적
- HTTP-only tools gateway에서 실제 커뮤니티 MCP를 흡수할 수 있는 personal MCP gateway로 확장한다.
- 운영 중 죽은 downstream, stuck session/job, long-running call 문제를 자동 격리한다.
- `resources/*`, `prompts/*` 등 MCP 명세 호환성을 보강한다.
- Makefile/scripts에 흩어진 운영 명령을 `coremcp` CLI로 묶어 매일 쓰기 쉽게 만든다.

## 개발 범위
- STDIO downstream bridge: `transport_type=http|stdio`, command/args/env 등록, subprocess JSON-RPC bridge, idle timeout, crash restart.
- 운영 안정성: circuit breaker, health probe, orphan session/job/inflight reaper, `coremcp doctor`.
- MCP 명세 확장: `resources/list/read/templates/list`, `prompts/list/get` 최소 proxy와 catalog cache.
- CLI: doctor/service add/validate/tool call/token issue/revoke/export/import skeleton.
- Web UX Phase 6는 backend API 안정화 후 Services 검색/필터/sort와 Playground schema form/replay/diff 중심으로 반영한다.

## 제외 범위
- Team/workspace/multi-user, public marketplace, publisher, billing.
- 외부 LLM API 호출 또는 LLM 내장 기능.
- sampling/elicitation 양방향 agent RPC full support.
- OpenTelemetry, audit hash-chain, plugin sandbox runtime.
- Kubernetes/Postgres migration/Tailscale Serve 자동화.
