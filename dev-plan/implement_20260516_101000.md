# implement_20260516_101000.md

작성 일시: `2026-05-16 10:10:00 KST`

이 문서는 이번 개발의 범위를 고정하고, 구현이 목적 밖으로 확장되지 않도록 하기 위한 작업 문서다.

## 개발 목적
- 남은 구조 안정화 후보를 이번 범위 안에서 마무리한다.
- 기능 확장 없이 repository, services route, MCP handler 의존 구조를 정리한다.

## 개발 범위
- `repository.py`의 service/catalog/toolbox domain을 mixin 파일로 물리 분리한다.
- `services.py`의 CRUD endpoint를 별도 파일로 물리 분리한다.
- `mcp/*` handler가 `app.state`에 직접 접근하는 지점을 `McpHandlerContext`로 점진 축소한다.
- built-in plugin과 resources/prompts hook은 별도 보안 ADR/dev-plan 전까지 계속 보류한다.

## 제외 범위
- built-in plugin 구현, resources/prompts plugin hook 구현은 제외한다.
- repository 전체 ORM/SQLAlchemy 전환은 제외한다.
- UX/기능 변경, SaaS/team/marketplace/billing 기능은 제외한다.
- 외부환경 검증은 제외한다.
