## 개발 목적

CoreMCP Web Admin 내부에 Codex CLI exec 기반 챗봇형 시뮬레이터를 추가한다. 사용자가 “연결된 AI client가 CoreMCP 도구함을 실제로 어떻게 사용하는지”를 Web UI에서 바로 확인할 수 있게 한다.

핵심 목적은 CoreMCP가 LLM 서비스가 되는 것이 아니라, 이미 등록된 Codex CLI exec client가 CoreMCP `/mcp` 도구함을 호출하는 흐름을 관리자 화면에서 안전하게 시뮬레이션하는 것이다.

## 개발 범위

- Web Admin 메뉴에 `AI Client Simulator` 페이지 추가
- Admin API에 `POST /v1/simulator/codex/run` 추가
- 기존 `infra/scripts/codex-exec-coremcp.sh`만 실행 경로로 사용
- prompt preset과 자유 입력 UI 제공
- Codex stdout/stderr, exit code, duration, MCP tool call trace 표시
- project_docs MCP 사용 예시를 기본 preset으로 제공
- admin bearer 인증, prompt 길이 제한, timeout, subprocess 종료 처리 적용
- route smoke와 README/Makefile 문서성 갱신

## 제외 범위

- CoreMCP에 외부 LLM API dependency 추가 금지
- Codex 이외 Claude/Cursor 직접 실행기 추가 금지
- streaming chat/SSE 구현 제외 — 이번 범위는 request/response 실행
- 실행 history DB 저장 제외 — UI session 상태만 사용
- SaaS/team/workspace 기능 제외
- 임의 shell command 실행 제외 — Codex wrapper script만 허용
