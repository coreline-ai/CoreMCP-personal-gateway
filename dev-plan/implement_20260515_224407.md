이 문서는 MCP resources/prompts handler 본체를 `main.py` 밖으로 분리하는 안정화 작업 범위를 고정한다.

## 개발 목적

- `_handle_resources_*`, `_handle_prompts_*` handler 본체를 dedicated module로 이동한다.
- `/mcp` dispatcher wiring은 dependency injection으로 유지한다.
- `tools/call`, `_refresh_tools`, RPC helper, repository 본체 분해는 다음 Phase로 남긴다.

## 개발 범위

- `coremcp.mcp.resources_handlers` 신설.
- `coremcp.mcp.prompts_handlers` 신설.
- `main.py`에서 resources/prompts inline handler 제거.
- dispatcher handler wiring을 새 module wrapper로 교체.
- 구조/회귀 테스트와 문서 갱신.

## 제외 범위

- `_handle_tools_call` 이동.
- `_handle_tools_list`, `_refresh_tools` 이동.
- `_request_service_rpc`, `_request_default_downstream_rpc` 이동.
- repository.py 본체 분해.
- Plugin built-in/외부 loading.
