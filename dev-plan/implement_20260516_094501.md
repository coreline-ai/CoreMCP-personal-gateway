## 개발 목적
- 확장 개발 없이, 남은 구조 안정화 후보만 처리한다.
- `tools/call` logging/error 중복, services router endpoint 비대, repository god-object, app.state 직접 접근을 점진 완화한다.

## 개발 범위
- `handle_tools_call`의 invocation/error 기록 helper를 추가 분리한다.
- `api/services.py` endpoint별 공통 helper를 추가해 create/patch/credential 흐름의 중복을 줄인다.
- `repository.py` domain split 2차로 audit domain을 mixin으로 물리 분리한다.
- `Depends(...)` provider를 health/meta 경로부터 점진 도입한다.
- Plugin resources/prompts hook은 ADR-041에 따라 보류한다.

## 제외 범위
- built-in plugin, resources/prompts plugin hook, external plugin loading은 제외한다.
- repository 전체 SQL 이동은 제외하고 audit domain 1개만 second slice로 분리한다.
- UX/기능 변경, SaaS/team/marketplace/billing 기능은 제외한다.
- 외부환경 검증은 제외한다.
