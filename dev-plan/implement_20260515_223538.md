# implement_20260515_223538.md

작성 일시: `2026-05-15 22:35:38 KST`

이 문서는 `/mcp` 핵심 handler 주변 helper를 단계적으로 분리해 `main.py` 비대화를 줄이되, MCP 동작은 보존하기 위한 안정화 작업 문서다.

## 개발 목적

- MCP handler helper 중 순수 변환/카탈로그 helper를 먼저 분리한다.
- `/mcp` 핵심 tools/call handler와 repository 본체 분해는 다음 안정화 Phase로 남긴다.
- route 추가/기능 확장은 하지 않는다.

## 개발 범위

- `coremcp.mcp.catalog`: 도구함 service 조회 / unavailable service 메타 helper.
- `coremcp.mcp.resources`: cached resource 변환, URI collision 필터, resources/read truncate helper.
- `coremcp.mcp.prompts`: cached prompt 변환 helper.
- `main.py` import 및 call-site 교체.
- 구조/회귀 테스트 및 문서 갱신.

## 제외 범위

- `_handle_tools_call` 본체 이동.
- `_refresh_tools`, `_request_service_rpc` 전체 이동.
- repository.py 본체 도메인 분해.
- Plugin built-in/외부 loading.
