## 개발 범위
- `validate_service` / health probe 경로가 공통 MCP RPC helper를 재사용하도록 정리한다.
- `repository.py` 본체 분해 전 단계로 domain facade call-site를 추가 이관하고, 본체 분해 경계를 문서/테스트로 고정한다.
- built-in plugin 도입 전 예외/보안 ADR을 세분화한다.
- `Content-Length`가 없는 streaming body도 byte 단위로 제한한다.
- 회귀 테스트와 문서 카운트를 갱신한다.

## 제외 범위
- 새로운 built-in plugin 추가, 외부 plugin loading, access group, SaaS 기능은 제외한다.
- `repository.py`의 SQL 구현을 대량 이동하는 위험한 대수술은 제외하고, facade 경계와 call-site migration을 우선한다.
- 외부 환경 검증(reboot/Tailscale/real OAuth/mobile/long soak)은 이번 로컬 코드 안정화 범위에서 제외한다.
- 기능 UX 변경은 제외한다.
