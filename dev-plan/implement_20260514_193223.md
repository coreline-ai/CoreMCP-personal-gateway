# implement_20260514_193223.md

작성 일시: `2026-05-14 19:32:23 KST`

이 문서는 8개 가상 MCP demo server를 CoreMCP personal gateway에 연결 가능한 형태로 구현하기 위한 작업 문서다.

## 개발 목적

CoreMCP Web Admin의 MCP 추가/등록, validation, 도구함, Tool Control preset, Playground 흐름을 실제 외부 credential 없이 보여줄 수 있는 demo MCP suite를 만든다.

## 개발 범위

- 하나의 실행 앱 `apps/demo-mcp-suite` 안에 8개 독립 MCP endpoint 제공
- 각 endpoint는 CoreMCP에 별도 MCP service로 등록 가능
- 8개 demo:
  - Personal Ops Desk MCP
  - Local Knowledge Vault MCP
  - Project Task Board MCP
  - Bookmark Research MCP
  - Design Asset Catalog MCP
  - Fake Finance Ledger MCP
  - Home Lab Status MCP
  - Travel Planner MCP
- 공통 JSON-RPC MCP method:
  - `initialize`
  - `tools/list`
  - `tools/call`
  - `ping`
  - `notifications/initialized`
  - `notifications/cancelled`
- 각 demo는 read-only/write/destructive tool을 포함해 CoreMCP `readonly`, `dangerous_off`, `full_access` preset을 시연 가능하게 한다.
- README와 registration sample을 제공한다.

## 제외 범위

- 외부 LLM API 연동
- 실제 금융/개인정보/계정 credential 연동
- SaaS marketplace/team/workspace 기능
- 영속 DB 저장
- 실제 macOS service restart/backup 실행
- 실제 웹 크롤링/실시간 여행/금융 데이터 조회
