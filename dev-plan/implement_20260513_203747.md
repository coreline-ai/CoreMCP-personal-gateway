이 문서는 CoreMCP Web Admin의 디자인 스타일/테마를 코드 레벨로 분석하고, `docs/design/`에 디자인 문서와 asset을 정리한 뒤, 같은 디자인 언어를 전체 UI에 반영하기 위한 작업 문서다.

## 개발 목적

CoreMCP는 개인용 MCP Gateway 운영 콘솔이다. 이번 작업의 목적은 SaaS 랜딩페이지처럼 확장하는 것이 아니라, 현재 구현된 `/services`, `/toolbox`, `/clients`, `/settings`, `/playground`, `/logs`, `/services/[id]` 화면을 하나의 전문적인 운영 콘솔 디자인 시스템으로 정돈하는 것이다.

## 개발 범위

- 현재 Web Admin 코드의 Tailwind theme, global CSS, component class usage를 분석한다.
- `docs/design/`에 스타일 가이드, 코드 레벨 audit, component pattern 문서, asset을 추가한다.
- 반복되는 card/button/input/section/header 스타일을 CSS component layer로 토큰화한다.
- 기존 기능/API 흐름을 변경하지 않고 시각 일관성과 유지보수성을 개선한다.
- route smoke, lint, build로 회귀를 확인한다.

## 제외 범위

- SaaS marketing/marketplace/billing/team workspace 디자인 추가.
- shadcn/ui 도입 또는 대규모 컴포넌트 라이브러리 교체.
- 외부 font/CDN 의존성 추가.
- API 계약 변경.
- 실제 모바일 기기 수동 QA.
