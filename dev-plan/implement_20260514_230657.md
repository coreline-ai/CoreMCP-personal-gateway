# implement_20260514_230657.md

작성 일시: `2026-05-14 23:06:57 KST`

이 문서는 MCP 전문가 리뷰에서 지적된 명세 정합성 항목을 현재 코드 기준으로 재검증하고, 실제 미해결 항목만 좁게 패치하기 위한 작업 문서다.

## 개발 목적

CoreMCP personal gateway의 MCP Streamable HTTP/SSE 카탈로그 알림 정합성을 높인다. 특히 `notifications/tools/list_changed` 단일 송신으로 resources/prompts catalog가 stale 될 수 있는 문제와 SSE reconnect 시 `Last-Event-Id` backfill이 없는 문제를 해결한다.

## 개발 범위

- `notifications/{tools,resources,prompts}/list_changed` 카테고리별 송신 지원.
- service catalog 변경 시 tools/resources/prompts 변경 신호를 모두 송신하고, toolbox/tool permission 변경 시 tools 신호만 송신.
- `Last-Event-Id` 기반 SSE reconnect backfill을 위한 in-memory ring buffer 추가.
- unknown protocol version negotiation warning을 명시해 silent downgrade 위험 완화.
- 이미 구현된 항목(STDIO resource limits, idempotency cache invalidation, Keychain stdin, reaper shutdown)은 재구현하지 않고 검증/문서화만 한다.

## 제외 범위

- JSON-RPC batch 지원.
- notifications/progress streaming.
- notifications/resources/updated fan-out.
- resources subscribe/unsubscribe capability 변경.
- `main.py` / `repository.py` 대규모 모듈 분해.
- SaaS/team/workspace/marketplace/billing 기능.
- 외부 LLM API 의존성 추가.

### 구현 태스크

- [x] service validate/update/delete는 tools/resources/prompts 모두 publish.
