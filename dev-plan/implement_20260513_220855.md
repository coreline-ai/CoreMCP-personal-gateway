이 문서는 CoreMCP Web Admin의 기본 dark theme와 테마 선택 UI를 구현하기 위한 작업 문서다.

## 개발 목적

현재 Web Admin에는 dark theme 선택 UI가 없고 `color-scheme: light`만 적용되어 있다. Multica 디자인 원칙에 맞는 dark token을 추가하고, 기본값을 dark로 설정하며, sidebar에서 Light/Dark/System을 선택할 수 있게 한다.

## 개발 범위

- 기본 dark theme 활성화.
- CSS variable 기반 dark token 추가.
- 기존 hardcoded slate/semantic utility가 dark에서 깨지지 않도록 보정.
- sidebar admin 영역에 theme selector 추가.
- 선택값을 `localStorage`에 저장.
- 문서와 검증 상태 갱신.

## 제외 범위

- 외부 theme library 도입.
- backend/API 변경.
- OAuth/CIMD 변경.
- SaaS workspace/theme 설정 기능 도입.

## 공통 진행 규칙

- CoreMCP admin/client token은 downstream으로 전달하지 않는다.
- admin token storage 정책은 sessionStorage 그대로 유지한다.
- theme 선택값만 localStorage에 저장한다.
- 외부 dependency를 추가하지 않는다.
